## 🛠️ Użyte technologie
Projekt został stworzony przy użyciu podstawowych technologii webowych:
* **HTML5** – struktura i zawartość strony
* **CSS3** – wygląd, style i responsywność (opcjonalnie)

---

## 📂 Struktura plików
* `index.html` – główny plik startowy strony
* `README.md` – dokumentacja projektu (ten plik)

---

## 💻 Jak uruchomić projekt lokalnie?
1. Pobierz pliki z tego repozytorium na swój komputer (używając przycisku *Code -> Download ZIP* lub komendy `git clone`).
2. Kliknij dwukrotnie w plik `index.html`, aby otworzyć stronę w dowolnej przeglądarce internetowej.
